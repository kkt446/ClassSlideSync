字段说明
  version    结构版本，将来改格式时用；读到更高版本也不会崩，按已有字段尽力解析
  decks      键 = Ledger.Key(课件路径)：全路径、去尾反斜杠、全小写；希沃伪键（SeewoBridge.KeyPrefix）
             原样小写。与 ledger.json 的桶键完全一致，所以两张表可以直接对 key 关联。
  subject    最近一次记录的科目（空科目不覆盖旧值），用于「按科目聚合」
  name       显示名，取台账的 FileLabel / 原始路径文件名（保留原大小写，不转小写）
  updatedAt  "yyyy-MM-dd HH:mm:ss"，最近一次写入时间；Decks() 按它倒序
  sessions   这份课件被记录过几场
  pages      页码 → { seconds 累计停留秒数（四舍五入到整秒）, visits 结算次数 }
             同一页来回翻，seconds 和 visits 都累加；95 秒 / 2 次 → 平均一次 47.5 秒
聚合 API
  PageDwell.Decks()            每份课件一行，带 Pages（深拷贝，随便改不影响内部）
  PageDwell.Deck(pathOrKey)    单份课件；没有就 null
  PageDwell.Subjects()         按科目聚合：TotalSeconds 降序、同秒按科目名；空科目归「未标注科目」

上限与清洗（写入侧 + 读取侧各做一遍）
  页号 <= 0、秒数 <= 0 直接丢；单页秒数夹到 21600；visits 夹到 100000；

  空科目不覆盖已有科目；空名字才用文件名兜底；坏 JSON 改名后空起。

剩余时间：四级回退链（功能 2）
--------------------------------------------------------------------
1. 本次课实测：turns >= 3 且 elapsed >= 60 秒时，用 elapsed / turns。
   turns 是「页面真的变了」的次数（同一页的重复快照不算），所以 2 → 30 的跳页只算 1 次，
   不会把速度虚算成几秒/页；往回翻一页再翻回来算 2 次。
2. 本课件历史均值：PagePace.Average(ledger.Recent(key, 200))，只统计 EndSlide > StartSlide 的记录。
3. 全库历史均值：本课件没数据时才扫。
4. 兜底 60 秒/页。
四条路的结果最后都过 ClampSecondsPerPage：[8, 600]。
卡片副标题仍走 PagePace.Remaining(isShowing, slideCount, current, secondsPerPage, out pages, out minutes)，
公式（ceil(left*秒/60)，不足 1 分钟按 1 分钟）与改动前逐点一致。

过程中发现并处理的问题
--------------------------------------------------------------------
1. 累加器桶键原来存原样路径（C:\课程\第一课.pptx），台账是 c:\课程\第一课.pptx →
   同一份课件会在 dwell.json 里被拆成两条。已改为 Begin 里走 Ledger.Key 归一（断言 T02/E04）。
2. 显示名兜底原来用归一后的 key，会把「课件A.pptx」写成「课件a.pptx」。改成用原始路径取文件名（S07/E31）。
3. 写入实测速度时，Advance 里两次 DateTime.Now 会差几毫秒（EndedAt 与 Seconds 不一致）。统一成一个 now。
4. 历史均值分支原来没夹取，脏台账（比如 1 秒/页）会把剩余时间算成「约 1 分钟」。现在统一夹 [8,600]。
5. harness 侧：System.Text.Json 9.0.2 依赖 System.IO.Pipelines 9.0，缺了会让 Save 在序列化阶段失败
   （只记 LastError、不落盘）。已在 harness 补引用 —— 结论是插件的失败兜底确实生效了（没崩、只少一份统计）。
6. 自测里最初把累加器时长写成「微秒级」翻页，导致整场都是 0 秒被丢掉；加了真实等待后恢复正常。
   这条也说明设计取舍：单页停留不足 0.5 秒会被四舍五入成 0 而不记录（当作噪音，不污染平均值）。
