一、根因（文件:行 + 改前代码）

1)「打开文件夹」完全不弹：路径用了给左栏看的省略串
   Ui\ControlPanel.axaml.cs  OnOpenFolderClick（改前约 946 行）第一行：
       var folder = selectedRow?.Item.Folder;
   Item.Folder 来自 Core\CardFileList.cs 的 FolderOf()，是显示用的省略路径
   （形如 "…\panel-buttons\media"，永远带 "…\"），不是真实目录。
   因此 Directory.Exists(folder) 恒为 false，方法只提示
   “文件夹不在了，可能已被移动或删除：…” 就 return，openFolder 委托一次都没调用
   → 服务/宿主收不到目录，explorer 永远不弹。
   修复前 harness 实测： opens=0 folder='' hint='文件夹不在了，可能已被移动或删除：…\panel-buttons\media'

2)「立即跳转」请求被服务静默吃掉：未上课时 engine == null 直接 return
   Services\SlideSyncService.cs  RequestJump(string, int)（改前约 999 行）：
       var e = engine;
       if (e == null) return;
   engine 只在 Arm()（开始上课/放映）里创建，Disarm() 时置 null
   （SlideSyncService.cs:581/630/650 创建，679/689 置空）。
   没在上课时点跳转：无日志、无提示、无任何动作。
   面板 OnJumpClick 又在调用后写“已请求跳到第 N 页”，看起来像成功，实际引擎没收到。
   真机 app.log（ClassIsland\data\Config\Plugins\ClassSlideSync.Plugin\app.log）
   10-25 13:08 以后只有 panel: opened，没有任何 panel: jump 行，与此一致。

3) 次要静默点
   - Select（改前）按 selectedPage > 0 / item.Folder 非空置灰两个按钮；
     RefreshSelectedDetail 也会把 JumpButton 重新置灰。点灰按钮零反馈，和“按钮坏了”同感。
   - RequestJump（面板）在 JumpRequested == null 时直接 return，没有提示。
   - 希沃伪键（希沃:课程名）在面板被提前拦成“没法自动跳页”，没走引擎的 SeewoBridge.GotoSlide；
     拿伪键去 Process.Start / Navigate 必然失败。
   - 文件被移走时没有统一提示。

五、现在点这两个按钮会发生什么

1. 选中一份有记录的课件点「立即跳转」：面板立刻显示“正在跳转…”，app.log 记
   “panel: jump -> <文件> 第 N 页”；上课中经 SessionEngine.RequestJumpTo 让 PPT/WPS 翻到第 N 页
   （希沃仍走 SeewoBridge.GotoSlide），引擎的最终结果（已跳到第 N 页/打不开 PowerPoint 等）再回写状态条；
   没上课则明确提示“现在没在上课…”，文件被移走则提示“找不到这份课件的文件…”，不会再静默。
2. 点「打开文件夹」：用真实文件目录（不再用 “…” 省略路径）经 IUriNavigationService/ShellExecute
   打开 explorer，app.log 记 “panel: open folder <目录>”，成功提示“已打开文件夹：…”；
   目录被移走提示“找不到这份课件的文件夹，可能已被移动：…”，希沃行提示“希沃课件没有本机文件夹，台账里只有课件名”。
