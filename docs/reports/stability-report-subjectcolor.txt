五、没做到 / 需要老师留意的地方
------------------------------------------------------------------------
1. 两个设置界面只过了 Avalonia XAML 编译校验，没做界面截图。
   harness 是纯反射、不引任何 NuGet，而 SettingsPageBase 来自 ClassIsland.Core
   （插件 csproj 里 ExcludeAssets=runtime，输出目录没有 ClassIsland.dll），要真机渲染
   设置页得给 harness 装 Avalonia + ClassIsland 依赖，超出了这次「不加 NuGet」的边界。
   风险点自评：新加的控件（SettingsExpander / ToggleSwitch / ComboBox / TextBox / ColorPicker /
   Button）和绑定写法都是照抄同文件里已有的行（含 HexColor 转换器、Options/UseDropdown 那套），
   编译期已经校验过类型、属性（IsAlphaVisible 等）和 Click 处理器存在，运行期炸的概率低。
   唯一没被编译期校验的是普通反射绑定的路径字符串（Settings.ShowPillPageNumbers、
   Settings.SubjectColors、UseDropdown/UseTextBox/Subject/Color），这些名字与 C# 成员逐字对过。
2. 药丸宽度在关掉页码后刻意保持不变（只多给进度条高度），避免老师一开关药丸就变宽变窄、
   贴着屏幕边缘时位置乱跳。如果希望关页码后药丸也变窄，需要再改 ComputePillWidth。
3. PrintWindow 抓不到分层窗口的 alpha，所以 75% 透明那张图看起来和不透明一样；
   透明度本身没改过，沿用原来的 PillAlpha 逻辑。
4. 插件里本来就没有 WM_DPICHANGED 处理（dpi 只在窗口创建时 DpiOf() 取一次），
   所以 144dpi 是用反射改私有 dpi 字段 + ApplyLook() 模拟的；跨屏拖动时 dpi 不刷新是既有行为，
   不是这次引入的。
5. 科目识别依赖课件「有标记科目」或课表给了 subject：两者都没有时进度条回落主题强调色
   （例如「未标注科目」的旧课件、临时拖进来的 PDF）。这是设计如此，不是 bug。
6. 「恢复预设色」会清掉老师自己改过的颜色（按钮语义就是还原），没有二次确认弹窗。
7. 未做老配置迁移测试（模拟升级场景）：因为新字段都有默认值、配色表为空时自动回落内置 14 色，
   理论上老 settings.json 直接可用，但没有真的拿一份旧配置文件跑一遍。
