   L16  public static class LedgerCsv
   L19  Header 常量：
        "日期,周几,第几节,科目,课件名,起始页,结束页,总页数,时长(分),文件路径"
   L29  Collect(Ledger?)：遍历 ledger.ByFile 汇总全部 SessionRecord；按 StartedAt
        倒序（新的在前），解析不了时间的排最后；用 OrderByDescending 的稳定排序，
        同一时间保持原顺序 —— 老师想先看到最近那节课，且重复导出顺序固定。
   L58  ToCsv(IEnumerable<SessionRecord>?)：表头 + 每条一行，行尾 CRLF（CSV 标准，
        Excel/WPS 都认）；日期列也走 Escape，避免将来格式改动漏转义。
   L88  ToBytes(...)：new UTF8Encoding(true).GetPreamble() 拼正文，产出真正的
        EF BB BF 头 —— Excel 靠 BOM 判 UTF-8，否则中文列名和课件名乱码。
   L101 StatusText(int count, string? path)："已导出 N 条到 路径"，状态条文案统一由
        纯函数生成，测试不用拼字符串。
   L107 SuggestedFileName(DateTime now)："课件续页-记录-yyyyMMdd.csv"，
        InvariantCulture 格式化 —— 台账踩过 ar-SA 文化把日期写成 Hijri 的坑。
   L116 Escape(string?)：含逗号、双引号、CR、LF 时整体加双引号，内部双引号翻倍；
        null/空串写空字段。
   L133 DateText(string?)：DateTime.TryParse(..., InvariantCulture, DateTimeStyles.None)
        后输出 yyyy-MM-dd；解析失败原样回退，宁可让老师看到原始字符串也不丢信息。
   L147 WeekdayText(SessionRecord?)：Weekday 1..7 直接映射周一..周日；为 0（老记录
        没存）时从 StartedAt 反推，((int)DayOfWeek + 6) % 7 + 1（周日=7）。
   L168 PeriodText(SessionRecord?)：Period>0 写数字；否则写 PeriodName（"上午第 2 节"
        这类数不出来的记录）；再否则空。
   L180 DeckName(SessionRecord?)：FilePath 是 "希沃:" 伪键时去掉前缀
        （SeewoBridge.KeyPrefix），否则 System.IO.Path.GetFileName；
        GetFileName 对非法字符会抛 ArgumentException，catch 后回退整串 —— 台账键
        来自外部，不能假设一定合法。
   L204 TotalSlides(SessionRecord?)：SlideCount>0 用它，否则退到 EndSlide（老记录没有
        SlideCount 字段）。
   L214 DurationMinutes(int seconds)：seconds/60 向下取整，负数按 0。
   L221 TryParseStartedAt(string?, out DateTime)：集中解析入口，InvariantCulture。

3. Ui\ControlPanel.axaml.cs（703 行）
   L43–44 新增字段：
        bool exporting;       // 防连点：异步对话框期间重复点击会开两个保存框
        bool exportHintShown; // 区分"还没有记录"提示与真正的导出结果
   L102 构造函数末尾调用 UpdateExportState()，首屏就按台账条数定按钮态。
   L242–249 UpdateStatus(int shown) 末尾调 UpdateExportState()：台账增删后
        （Reload/Rebuild 都会走这里）按钮可用性立即跟上，不必手动刷新。
   L271 async void OnExportClick(object? sender, RoutedEventArgs e)：
        1) exporting 为真直接 return（防重入）；
        2) LedgerCsv.Collect(ledger) 先拍快照 —— 保存对话框是异步的，期间
           SessionEngine 可能正往里加记录，快照保证写出的行数与状态条 N 一致；
        3) 快照 0 条：ShowEmptyHint() 后 return，不弹对话框（让老师对着一本空台账
           选路径没有意义）；
        4) TopLevel.GetTopLevel(this) 取 StorageProvider（Avalonia 11 官方写法，
           见 docs.classisland.tech/dev/settings-page.html 与
            https://docs.avaloniaui.net/docs/concepts/services/storage-provider/）；
           取不到 → 状态条报错 return；
        5) SaveFilePickerAsync(new FilePickerSaveOptions {
             Title = "导出记录",
             SuggestedFileName = LedgerCsv.SuggestedFileName(DateTime.Now),
             DefaultExtension = "csv",
             ShowOverwritePrompt = true,
             FileTypeChoices = CSV 一项 });
        6) file == null → 用户取消，直接 return，状态条一个字都不改；
        7) TryGetLocalPath() 为空（云端/虚拟位置写不了）→ 报"这个位置不能直接写入，
           请选本机磁盘上的文件夹"；
        8) WriteExport(path, records)；
        9) catch (Exception ex) → ShowExportStatus("导出失败：" + ex.Message) + Log，
           异常止步于 UI 线程内，不冒出 async void 之外（async void 里漏出的异常会
           直接崩进程，所以整段必须包住）；
       10) finally → exporting=false; UpdateExportState()（恢复按钮态，UpdateExportState
           本身再套 try/catch，免得 finally 里二次抛）。
   L354 void WriteExport(string path, List<SessionRecord> records)：
        File.WriteAllBytes(path, LedgerCsv.ToBytes(records)) → ShowExportStatus(
        LedgerCsv.StatusText(records.Count, path)) → Log。同步写：台账通常几十 KB
        到几百 KB，同步写完再更新状态条最简单，也不会在离线测试里因为等待
        未 pump 的消息泵而丢状态；单独抽成方法是为了离线测试能直接调它验证
        真实落盘，而不必去点真实系统对话框。
   L367 void UpdateExportState()：
        has = RecordCount() > 0；
        ExportButton.IsEnabled = has && !exporting；
        ToolTip.SetTip(ExportButton, has ? "把整本台账导出成 CSV（Excel 可直接打开）"
                                         : "还没有记录")；
        has 且台账为空时把 ExportStatusText 设成"还没有记录"并显示（exportHintShown
        标记这是提示，不是导出结果）；has 为真后只撤掉这条提示，不覆盖已有导出结果。
   L395 void ShowEmptyHint()：置提示并显示"还没有记录"，供 0 条分支与测试调用。
   L402 void ShowExportStatus(string text)：设置并显示 ExportStatusText，同时把
        exportHintShown 置 false（从此这条是结果，不再被空台账逻辑撤掉）。

二、导出列映射（一行 = 一条 SessionRecord）

列名        来源
日期        StartedAt → InvariantCulture 解析 → yyyy-MM-dd；解析失败原样输出
周几        Weekday 1..7 → 周一..周日；0 → 从 StartedAt 反推；都失败留空
第几节      Period>0 → 数字；否则 PeriodName；再否则空
科目        Subject
课件名      FilePath 为 "希沃:…" 伪键 → 去前缀；否则 Path.GetFileName(FilePath)
起始页      StartSlide
结束页      EndSlide
总页数      SlideCount>0 ? SlideCount : EndSlide
时长(分)    Seconds / 60（向下取整，负数按 0）
文件路径    原始 FilePath 原样保留（希沃记录保留 "希沃:…" 伪键，方便老师回溯来源）

编码：UTF-8 带 BOM（EF BB BF），行尾 CRLF，字段含 , " CR LF 时加引号。
排序：按 StartedAt 倒序，新的在前；时间解析失败的排最后；同一时间保持原顺序。
默认文件名：课件续页-记录-yyyyMMdd.csv（InvariantCulture，不受系统文化影响）。

分类明细：
A. LedgerCsv 纯函数 —— 0 条 / 1 条 / 整行精确
   Collect(null)=0 条；0 条只写表头；单条"表头+1 行"；整行逐字段精确匹配；
   日期列只留年月日；斜杠日期也按 Invariant 解析；解析不了原样回退。
B. 多文化时间解析（5 种文化 × 3 断言）
   ar-SA / zh-CN / en-US / de-DE / ja-JP 下 ToCsv 输出完全一致、日期仍是
   yyyy-MM-dd、周几仍是周六；另有一条专门验证 ar-SA 下 2026-10-24 不被写成
   Hijri 日期。
C. 转义 / BOM / CRLF
   普通文本不加引号；逗号加引号；引号翻倍；换行加引号；空值与 null 写空字段；
   含逗号科目、含引号文件名、含换行科目都被正确包住；字节以 EF BB BF 开头；
   正文无额外 BOM 字符；每行以 CRLF 结尾；CRLF 数 = 表头 + 行数；无裸 LF、无裸 CR；
   字节长度合理。
D. 排序 / 时长 / 页数 / 文件名 / 状态文案
   Collect 汇总 4 条；新的在前 → 其次倒序 → 旧记录 → 解析失败的排最后；
   时长 59→0、60→1、2699→44、2700→45、-5→0；SlideCount=0 退到 EndSlide；
   SuggestedFileName 带日期；StatusText 文案正确；希沃伪键在"课件名"列去前缀、
   在"文件路径"列保留原键。
E. Avalonia 控件级断言（真实窗口，940×640）
   存在 OnExportClick 处理器；窗口尺寸 940×640；ExportButton 存在、有记录时可点、
   文案"导出记录"、高度 38、位置在搜索框右边且刷新按钮在其右边；有记录时
   ToolTip 是用途说明；未导出时不显示导出提示；状态条仍显示台账路径；
   面板台账共 8 条。
F. 真实落盘（反射调用 WriteExport，绕开系统对话框）
   CSV 已写出；磁盘文件带 BOM；内容 = 表头 + 8 行 + 末尾 CRLF；每行 10 个字段；
