2. 面板数据流
----------------------------------------------------------------------
卡片齿轮（浮层线程）
  → NativeOverlayCard.PanelRequested
  → SlideSyncService.OnPanelRequested
  → Dispatcher.UIThread.Post
      panel 已存在 → Show()/Activate()，绝不建第二个
      否则 → new ControlPanel(ledger, settings, () => lastState, OpenPanelFolder)
  → Window.Opened → Reload()
      stateProvider() 取当前 CardState
      从 st.Files 找 IsCurrent.Key
      CardFileList.Build(ledger, currentKey, 500, 1)   // 只读内存台账，无文件 IO 循环
  → Rebuild()：PanelData.Search(SearchBox.Text) → PanelData.Group(...)
  → Select(row)：PanelData.History(ledger, item, 200) 现读该文件完整历史
  → 立即跳转：ControlPanel.JumpRequested(filePath, slide)
      → SlideSyncService.OnPanelJumpRequested → RequestJump(filePath, slide)
  → 打开文件夹：openFolder 委托 → IUriNavigationService.Navigate，失败 ShellExecute

刷新按钮只重建左栏/状态条，读的是服务里同一个 Ledger 实例（引擎写入的就是它），
不重新 Ledger.Load：避免面板看到磁盘旧副本、和引擎内存里的记录打架。

构造函数（Ui\ControlPanel.axaml.cs:42）：
    public ControlPanel(Ledger ledger, SyncSettings settings,
                        Func<CardState>? stateProvider, Action<string>? openFolder = null)
openFolder 由服务注入，所以 ControlPanel 本身不直接引用 ClassIsland.Core 类型，
测试工程只加载 Avalonia/FluentAvalonia 就能构造窗口。

3. 齿轮绘制与命中
----------------------------------------------------------------------
几何（Ui\NativeOverlayCard.cs:318-340）与 Paint 共用同一份 ComputeTopIcons，
测试反射调用的也是它，不存在“测试一套、画图另一套”。

    int S(int v) { return (int)Math.Round(v * dpi / 96.0); }
    int pad = S(14);
    var arrow = new Rect32(width - pad - S(16), S(6), width - pad + S(2), S(6) + S(18));
    int icon = S(FolderIconSize);                  // 24
    int iconY = Math.Max(S(6), S(6) + (S(18) - icon) / 2);
    int folderX = arrow.L - S(10) - icon;
    // showPanel 时：
    int panelX = folderX - S(14) - icon;
    PanelIcon = (panelX, iconY, panelX+icon, iconY+icon);
    PanelHit  = 四周各外扩 S(6);

96dpi（卡片宽 236）：
    面板图标 134..158，命中区 x 128..164，y 0..36
    文件夹   172..196，命中区 x 166..202，y 0..36
    收起箭头 206..224
    齿轮/文件夹命中区间隔 2px；文件夹/箭头间隔 4px；全部在客户区内。
144dpi（卡片宽 354）：
    面板图标 201..237，命中区 x 192..246，y 0..45
    文件夹   258..294，命中区 x 249..303，y 0..45
    收起箭头 309..336
    齿轮/文件夹间隔 3px；文件夹/箭头间隔 6px；全部在客户区内。
（齿轮-文件夹间距用 14 逻辑像素：若用 10，两个 6px 外扩命中区会重叠 2px。）

齿轮画法（GdiCanvas 只有 FillRounded/StrokeRounded，没有多边形）：
    disc=Round(size*0.30)  hole=Round(size*0.13)  outer=Round(size*0.46)
    inner=Round(size*0.26) tw=Round(size*0.17)
    4 个轴向齿 + 4 个 45° 斜齿（中心取 inner/outer 中点，d=mid*0.7071）全部 FillRounded；
    再用轮盘盖住齿根，最后用卡片背景色在圆心挖一个洞 —— 负空间画法，不描边也认得出是齿轮。
24px 时：轮盘半径 7、孔 3、齿外径 11、齿宽 4。

命中区外扩 6px 的点击判定在 OnClick（NativeOverlayCard.cs:1349）：
    if (panelHit.R > panelHit.L && Inside(panelHit, x, y)) { PanelRequested?.Invoke(); return; }
放在 filePanel/historyPanel 分支之前、整卡跳页之前，所以点齿轮不会误触跳页。

未改：BaseCardHeight=150、Place/ApplyWindowRegion/贴边计算、autoHideSeconds 与 15 秒收起。
为满足“命中区必须在客户区内”，24px 图标不能按 18px 行高居中（原公式 96dpi 得 y=3，
命中区顶端 -3；144dpi 得 -4），改为 Math.Max(S(6), ...)，文件夹图标因此下移 3/4 逻辑像素；
这不是卡片尺寸/贴边/收起的改动。
